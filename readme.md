# Electricity Bill Calculator

A PHP and MySQL based multi-page electricity bill calculator developed using XAMPP.

## Features

- User registration and login
- Electricity bill calculation using slab-wise rates
- Monthly bill storage using MySQL
- Monthly bill history
- Average monthly bill calculation
- Duplicate month prevention for each user
- Responsive interface

## Electricity Rates

- First 50 units: Rs. 3.50 per unit
- Next 100 units: Rs. 4.00 per unit
- Next 100 units: Rs. 5.20 per unit
- Above 250 units: Rs. 6.50 per unit

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside `C:\xampp\htdocs`.
4. Open phpMyAdmin.
5. Import `database.sql`.
6. Open the project at:

`http://localhost/electricity-bill-calculator/`
